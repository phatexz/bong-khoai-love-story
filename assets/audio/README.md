# Nhạc cho website Bông & Khoai

Đặt ba file nhạc tại thư mục này với đúng tên:

- `1.mp3` — Phần I
- `2.mp3` — Phần II
- `3.mp3` — Phần III

Website cũng có fallback để tìm `1.mp3`, `2.mp3`, `3.mp3` ở thư mục gốc nếu cần. Khi repo đã nối với Vercel, chỉ cần commit/push các file nhạc lên `main`; Vercel sẽ tự tạo deployment mới.

Lưu ý: chỉ sử dụng file âm thanh bạn có quyền sử dụng/chia sẻ.
